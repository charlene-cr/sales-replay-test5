# Implementation Risk Desk

The implementation risk desk converts replay notes into a weekly view of migration
and launch readiness. It is designed for sales managers who need to know which
accounts are drifting after technical validation, which accounts need executive
air cover, and which owners have the largest follow-up queue.

### Sponsor coverage review 1

Account teams use this checkpoint to compare replay signals against implementation risk.
Managers should confirm the recorded blocker, named next step, and whether the sponsor
is still active before escalating the deal. The desk is intentionally compact so weekly
forecast calls can move from risk identification to named action within the same review.
