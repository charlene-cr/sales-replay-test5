# Pricing Concession Tracker

The pricing concession tracker turns replay evidence into a structured review of
discount pressure. It helps managers separate normal procurement movement from
unqualified concessions that need stronger value proof.

### Approval checkpoint 1

Use this checkpoint to confirm whether a concession has a named approval stage, a
value proof artifact, and a clear next action. Managers should look for discount
requests that mention competition without attaching replay evidence from the buyer.
