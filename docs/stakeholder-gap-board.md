# Stakeholder Gap Board

The stakeholder gap board turns replay notes into a manager-readable list of missing
personas, stale gaps, and next actions. It helps managers coach account teams before
a mutual plan stalls because the wrong person was missing from the conversation.

### Review lane 1

Use this lane to compare replay evidence with stakeholder coverage. The account owner
should confirm which persona is missing, what proof artifact is needed, and whether
the next call should include a manager, executive sponsor, or technical owner.
