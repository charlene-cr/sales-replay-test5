# Track renewal risk patterns

This module tracks renewal risk as a medium-sized replay analysis surface.

## Manager Workflow

1. Review the highest-priority scenarios first.
2. Ask the rep to quote the buyer signal in their own words.
3. Confirm the follow-up artifact has an owner and due date.
4. Compare the scenario against one won call and one open follow-up.
5. Add the resulting behavior change to the next manager brief.

## Review Questions

- What buyer language indicates renewal risk?
- Which owner needs coaching on the next call?
- Which account should appear in the weekly replay review?
- Which follow-up artifact would prove the rep understood the buyer?
- Which high-priority scenario should be escalated before forecast review?

## Acceptance Criteria

- Scenarios include account, owner, stage, score, and priority.
- The summary includes average score and high-priority count.
- Manager-facing text includes a recommended action.
- Fixture data is structured enough for spreadsheet export.
